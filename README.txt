INSTITUTO GORDON H. CLARK — 7.0
PUBLICAÇÃO GITHUB PAGES
1. Crie um repositório público no GitHub (ex.: estudosclarkianos).
2. Extraia este ZIP e envie todos os arquivos da raiz ao repositório.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Aguarde o endereço HTTPS exibido em Pages.
5. No Chrome Android, abra o endereço e use o menu Instalar aplicativo ou Adicionar à tela inicial.
6. Depois de obter o endereço real, configure canonical, sitemap.xml e Google Search Console. Não use um endereço fictício.
Atualizações: substitua arquivos no repositório e incremente CACHE em sw.js.
Conteúdo: catálogo seletivo; fontes externas podem impedir leitura embutida. Direitos de fotos não verificados.
Teste local: python -m http.server 8000 nesta pasta.
